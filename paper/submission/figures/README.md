# Current manuscript figures

Figures 6–7 show actual prediction replays: [spatial comparison](qualitative_spatial.png)
and [temporal window](qualitative_temporal.png). The [video supplement](../qualitative/README.md)
contains four synchronized clips with provenance. This is post-hoc, GT-aligned
visualization, not evidence of universal superiority. See `paper/QUALITATIVE_PLAN.md`.

2026-09-08: Figures 1–5 share a Helvetica, navy/teal/amber palette and light
rounded-panel style. Overall in-image titles/subtitles are omitted; panel labels,
units, legends and uncertainty definitions remain. All source CSVs were checked
byte-for-byte against the pre-style copy: no values or estimators changed.
Figure 2's vector rendering is generated by `scripts/paper_closeout_report.py`;
its curves are not smoothed or resampled. Captions retain the evidence limitations.

All figures below appear in [the latest Markdown draft](../../draft.md) and the
