# Figures for paper/draft.md

Status of the figure set. All nine are built.

The test applied when deciding what gets a figure is not "would a picture be
nice" but **does the claim live in a shape** — a curve, a distribution, a
spatial artefact. Where the claim is two numbers, the table stays: the
token-drop ablation and the design-decision comparisons are left as tables for
that reason.

The seven quantitative figures are generated by `scripts/make_figures.py`
from the tables in the draft — no hand-placed coordinates, so a changed number
moves its label with it. **The data blocks at the top of that script are copies
of the draft's tables, so they go stale when a table is re-measured**; Figures
3, 4 and 7 each drifted once that way before being caught.

    python scripts/make_figures.py --out paper/figures

The two raster figures come from the model rather than from a table:

    python scripts/viz_sawtooth.py --ckpt <reported> --out outputs/sawtooth
    python scripts/viz_qualitative.py --out paper/figures/qualitative.png

**Captions live in `caption.md`, not in the artwork.** The SVGs carry only axis
labels, panel letters and element annotations, so the files can be submitted
as-is and the journal typesets the caption. `caption.md` is the authoritative
wording and the inline captions in `../draft.md` mirror it. The two raster
figures carry column headers and row labels inside the image, because a grid of
tiles is unreadable without them; those are labels, not captions.

## Still missing

Nothing required. Two optional additions, neither blocking:

### Edge latency and energy

**Shows.** Table 13's two curves — latency and energy per frame against forced
activity on the Jetson Nano — against the flat dense line, on one pair of axes.

**Why it might be worth it.** The inverted ordering against the 4090 is the
paper's sharpest systems result and it currently lives only in a table. A
figure would make the crossing point visible.

**Why it is not required.** The claim is a ratio at one operating point, which
a table states exactly. **Effort.** Small — the data is already in Table 13.

### Range compression

**Shows.** Predicted against ground-truth disparity distribution on Bonn and
TUM, as overlaid densities or a quantile-quantile plot.

**Why not a table.** Table 10 gives one ratio per source. The claim is that the
whole *distribution* is narrowed, and a Q-Q plot shows immediately whether the
compression is uniform or concentrated in the tails — which the ratio cannot
distinguish and which points at different fixes.

**Data.** Needs a short inference pass to dump per-pixel values (a few minutes).
**Effort.** Small.
