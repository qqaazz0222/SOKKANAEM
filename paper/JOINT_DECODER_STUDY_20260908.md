# 공동 디코더 학습 및 세부 경로 기여도 — 2026-09-08

## 결론

**디코더 전체를 학습하면 경계 지표 일부는 개선되지만, 절대 거리 정확도와 평탄부
잡음까지 동시에 개선되지는 않았다.** 추가한 RGB 세부 경로의 이득도 확인하지 못했다.
채택한 새 모델은 없고, 원본 v11·논문·최종 테스트 결과는 그대로 유지했다.

이번에는 이전 실험의 고정된 마지막 특징만 학습하지 않았다. SSM의 디코더 입력 전
다중 블록 토큰을 캐시하여 원본 DPT의 투영·RGB stem·융합·head·bin 간격을 모두 학습했다.
SSM encoder 자체는 여전히 동결이다. 전체 네트워크 end-to-end 학습이나 사전학습
공간 encoder 교체를 수행한 것은 아니다.

## 1. 학습 가능성 검사

실제 개발 데이터에 앞서, 색상으로 구분되는 2m/4m 원형 전경·배경을 사용했다.
64×64, 학습 64개·별도 seed 검증 32개, RGB 독립 미세 잡음 추가, 토큰은 0이다.
쉽게 풀 수 있도록 설계한 구현 검사이며 실제 깊이 추정 성능 근거가 아니다.
검사에서 학습한 가중치는 실제 데이터 실험으로 이전하지 않았다.

첫 실행에서 기존 분위수 경계 F1을 gate에 쓰니 0.2655로 통과하지 못했다.
이 합성 GT는 대부분 완전히 평탄하여 일부 분위수 임계가 0이 되고, 평탄부의 아주 작은
예측 기울기까지 경계로 집계되는 문제가 있었다. 첫 결과는 삭제하지 않았다.

따라서 **이 합성 검사만** 고정 log-depth gradient >0.1, 위치 허용 2px의 경계 F1으로
계획을 수정하고 재실행했다. 기존 분위수 F1도 계속 기록했다.
실제 개발 및 논문의 sharpness 정의·채택 gate는 바꾸지 않았다.

| 합성 검사 | 초기 | 500 step 후 |
|---|---:|---:|
| AbsRel ↓ | 1.462363 | 0.022050 |
| 합성 전용 고정 임계 경계 F1 ↑ | 0.805975 | 0.927643 |
| 기존 분위수 경계 F1 참고값 | 0.144716 | 0.255370 |

수정한 검사 기준(AbsRel <0.08, 합성 전용 F1 >0.70)을 통과하여 실제 데이터 실험으로
이동했다. 이 변경은 첫 결과 관찰 후의 적응적 검사 수정이며 사전 확정 검증이 아니다.
기존 기준으로도 합격했다고 해석하면 안 된다. 잡음이 있는 평탄 GT에서 두 정의가
어떻게 다른지 고정 임계 단위 테스트를 추가했다.

## 2. 실제 데이터의 공동 학습

- 데이터: 이전 구조 실험의 학습 192클립·768프레임, 개발 16클립·128프레임 재사용.
  TUM/Bonn/VKITTI2 학습, TUM/Bonn 개발. 이미 관찰한 개발 장면·프레임이다.
- 선택 목록과 train/dev 분리는 부모 실험을 계승한다. reserved final은 사용하지 않는다.
- 입력 256×256, 기존 K30, clip 시작 상태 초기화. 학습 T=4, 개발 T=8.
- 캐시 RGB는 FP16→FP32로 사용하고, 이 RGB로 SSM을 다시 실행하여 **디코더 입력 토큰을
  FP32**로 저장했다. 기준 모델도 같은 RGB/토큰에서 재평가했다.
  기존 표와 입력 수치 경로가 조금 다르므로 아래의 재평가 기준값으로 비교한다.
- 대조 A: 원본 디코더만 학습(139,920 파라미터).
- 대조 B: 원본 디코더 + 새 1/2·1/4 RGB 세부 경로 공동 학습(148,120 파라미터).
  추가 8,200 파라미터의 시작 출력은 0으로 원본 특징을 보존한다.
- 두 실행 모두 1,600 step, batch 8, AdamW lr 3e-5, seed 734, 동일 minibatch 순서.
- 공통 손실: log-depth L1 + 0.5 전역 signed-gradient L1 +
  0.1 유효 GT 깊이 불연속의 signed-gradient L1. 유효 영역을 1px 침식하고,
  GT log-gradient >0.02를 불연속으로 정의했다. 이 처리는 교사 신뢰도 검증이 아니다.
- 변경된 학습률·손실·학습 범위 때문에 이전 회차와의 차이를 특정 요소 하나의
  인과 효과로 해석하지 않는다. 이번 A/B는 그 조건들을 동일하게 맞췄다.
- 최종 확대는 원본 bilinear이며, full-resolution 학습형 확대는 아직 하지 않았다.

## 3. 동일 조건 개발 결과

| 구성 | Raw AbsRel ↓ | Clip-median AbsRel ↓ | 경계 AbsRel ↓ | 경계 F1 ↑ | Overshoot ↓ | Flat-TV ↓ |
|---|---:|---:|---:|---:|---:|---:|
| 기존 v11 재평가 | 0.110890 | 0.081809 | 0.152880 | 0.342475 | 0.197014 | 0.026898 |
| 원본 디코더 학습 | 0.114658 | 0.080705 | 0.158932 | 0.351833 | 0.190934 | 0.028088 |
| 세부 경로 + 디코더 공동 학습 | 0.114708 | 0.080578 | 0.158970 | 0.351981 | 0.191150 | 0.028060 |

공동 학습의 경계 F1은 약 2.78% 상대 증가, overshoot는 약 2.98% 감소했다.
그러나 raw AbsRel은 약 3.44%, flat-TV는 약 4.32% 증가했다.
경계 픽셀의 실제 깊이 오차도 증가했다. Clip-median 보정 후 오차 감소를
보정 없는 metric 정확도 개선으로 표현해서는 안 된다.

두 실행 모두 기존 gate에서 raw 정확도·경계 깊이 정확도·flat-TV 등의 조건을 실패했다.
다중 seed·신뢰구간·장기 스트리밍·미지 도메인·장치 성능은 검증하지 않았다.

## 4. 세부 경로 제거 진단

공동 학습한 **동일 가중치**에서 RGB 세부 경로만 추론 시 제거했다.
이는 위 A/B와 별개의 사후 진단으로, 새로 학습한 독립 대조군을 대신하지 않는다.

| 지표 | 세부 경로 활성 − 제거 |
|---|---:|
| Raw AbsRel | +0.000607 |
| 경계 AbsRel | +0.000729 |
| 경계 F1 | −0.000222 |
| Overshoot | +0.000832 |
| Flat-TV | +0.000035 |

이 표본에서는 세부 경로를 켜는 것이 오히려 조금 불리했다.
또한 독립 A/B의 F1 차이는 약 +0.000148에 불과하다. 현재 세부 경로를
모델의 성능 기여로 주장하거나, 추가 연산을 정당화할 근거가 없다.
제거 후 모델도 원본보다 raw 정확도가 낮으므로 새 모델로 채택하지 않았다.

## 5. 현재 결정과 다음 우선순위

1. 현재의 추가 RGB 세부 경로·mixture 출력을 최종 모델에 반영하지 않는다.
2. 출력 보정의 반복 대신 **공간 encoder 표현의 품질**을 다음 독립 가설로 둔다.
   사전학습된 공간 encoder 또는 encoder-decoder 공동 학습 비교는 아직 미실행이다.
3. 그 전에 학습 데이터만으로 metric scale 변화와 경계 오차를 분해하고,
   학습량·감독·해상도를 맞춘 대조를 설계한다. 개발 GT를 이용해 최종 scale을 맞추지 않는다.
4. 검증된 공간 품질 후보가 생긴 뒤 캐시/시간 모듈, 새 평가 분할, Pi 4·Nano B01
   5W/10W 측정으로 이동한다. 작은 parameter 수를 속도·전력 개선으로 간주하지 않는다.

이번 결과는 SSM이나 세부 경로 구조의 보편적 한계 증명이 아니다. 제한된 학습 표본,
단일 seed, 동결 encoder와 현행 감독 아래에서 현재 구현이 통과하지 못했다는 결과다.
