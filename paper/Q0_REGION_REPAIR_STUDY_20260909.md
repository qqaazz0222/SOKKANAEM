# K2 출력 보존·불확실 영역 한정 보정 학습

후속: [학습형 Q0 전체 갱신 정책](Q0_LEARNED_SCHEDULING_STUDY_20260909.md).
재사용 판단은 일부 작동했으나 두 개발 구간의 품질과 기존 K2보다 빠른 속도를 함께 얻지 못했다.

2026-09-09. [K4 상태 전달 실험](Q0_RECURRENT_FLOW_STUDY_20260909.md)의 후속.

**통과했던 K2 출력-flow에 국소 보정기를 붙여 품질·가속 기준은 유지했다.
하지만 보정량이 사실상0에 가까워 실질적인 품질 향상은 입증되지 않았다.**
새 모듈을 개선 모델로 채택하지 않으며 기존 출력-flow 대조군과 논문 모델을 유지한다.

## 1. 이번 변경과 대조

- 전체 특징 cache를 수정하지 않는다. 기존 Q0 전체 갱신 / nearest 깊이 이동의 K2 출력을 base로 쓴다.
- 기존 DIS forward/backward·밝기·범위 검사·erosion의 신뢰도 mask를 그대로 사용한다.
  그 반대 영역만 editable로 삼는다. **실제 가림 해제 정답이 아니라 RGB 대응 불확실성 proxy**다.
- 현재 RGB, 흐름으로 이동한 이전 RGB, 두 RGB의 절대 차이, base log-depth, editable mask를11채널로 입력한다.
- 작은 CNN22,433params가±.03 log-depth residual을 출력한다. 마지막 head는0으로 초기화한다.
- 국소형은 editable mask의5×5 평균으로 경계 부근 보정량을 줄이고, mask 밖은 `torch.where`로 base를 정확히 복사한다.
  두 깊이장을 강하게 교체하지 않고 작은 residual만 허용한다.
- CNN은 전체 프레임을 계산한다. **수정 출력의 영역 제한이지 sparse CNN 연산 또는 SSM의 고유 기여가 아니다.**
- 같은 구조·초기 가중치·표본 순서·예산으로 국소형과 전체형을 각각 학습했다.
  학습 후 각 가중치를 국소/전체 양쪽으로 적용해2×2 대조를 했다.
  국소 학습 가중치를 전체에 적용한 행은 학습 때 수정하지 않았던 영역에 대한 사후 대조다.

## 2. 학습 조건

원래 training192클립·768프레임에서 K2 생략384쌍을 사용했다.
직전 연구의 training-only Q0/flow cache를 해시 검증 후 재사용했다. 개발·최종 자료를 학습에 넣지 않았다.
Training/development 파일 경로 교집합0 및 reserved final sequence 제외를 확인했다.

- 각1,200step, 총2,400step. Batch4, AdamW lr.0005, seed740.
- 같은 저장된1,200×4 index 배열로 두 모델을 학습했다. 첫 손실도 .1741775274로 동일했다.
- Q0는 동결, 개발 입력518/점수256. 개발 L32 256프레임 /L256 1024프레임은 기존 자료를 재사용했다.
- 최종 checkpoint만 평가하고 중간 개발 점수에 따른 선택은 하지 않았다.

손실은 다음과 같다.

`5×Q0 log-depth L1 + 10×Q0 multiscale log-gradient L1`
`+ 10×base보다 증가한 Q0 depth error + 10×base보다 증가한 Q0 gradient error`

이전의 training-GT-flat 손실은 사용하지 않았다. Depth/gradient 오차 증가의 양의 부분을 벌점으로 준다.
이 **학습 벌점은 추론 시 무손상 보장이 아니다**. 보장한 것은 국소 mask 밖의 출력 값 동일성뿐이다.
이전 특징 학습과는 base/구조/목적함수가 함께 달라졌으므로 손실 하나만의 효과를 분리한 실험은 아니다.

## 4. 보정량 및 영역 진단

### 실제 보정은 거의 꺼진 상태에 가까움

| 국소 학습/국소 적용, 생략 프레임 | L32 | L256 |
|---|---:|---:|
| 전체 픽셀 평균 절대 log-depth 수정량 | 3.03×10⁻⁷ | 3.60×10⁻⁷ |
| 최대 절대 log-depth 수정량 | 6.44×10⁻⁶ | 6.20×10⁻⁶ |
| 수정량>10⁻⁴인 픽셀 비율 | 0% | 0% |

전체 학습/전체 적용도 L256 평균4.51×10⁻⁶, 최대5.48×10⁻⁶으로 매우 작았다.
따라서 품질 통과는 성공적인 복원보다 **base에 매우 가까운 출력으로 수렴한 결과**로 해석한다.
강한 오차 증가 벌점이 수정을 억제했을 가능성이 있지만, 별도 벌점 계수 ablation 없이 유일 원인으로 확정하지 않는다.

### 불확실 영역이 오류 위치를 얼마나 포착하는가

| 픽셀 가중 진단 | L32 | L256 |
|---|---:|---:|
| 수정 가능 영역 비율 | 25.07% | 30.28% |
| Q0 오류 proxy precision | 54.05% | 66.05% |
| Q0 오류 proxy recall | 33.12% | 36.57% |

오류 proxy는 `Q0 log-depth 차이>.015` 또는 `인접 log-gradient 차이 합>.02`다.
이는 GT 정확도·가림 정답·optical flow 정답이 아니다. Mask의 모든 픽셀이 새로 드러난 물체인 것도 아니다.
특히 mask는 이 proxy 오류의 상당 부분을 놓치므로, 영역 제한만으로 필요한 갱신을 모두 표현하지 못한다.
위 비율은 픽셀 가중이며 본문 품질 점수의 source/scene-balanced 집계와 다르다.

## 5. 배포 불가능한 Q0 참조 진단

보정량과 영역 제한을 분리해 살펴보기 위해 현재 dense Q0가 이미 있다고 가정한 사후 oracle 두 개를 계산했다.
실제로는 생략 프레임의 Q0가 없으므로 배포 가능한 모델이 아니며 속도도 부여하지 않는다.

- **Bounded:** 현재 Q0와의 log-depth 차이를±.03×국소 taper 한계로 제한해서 editable 안에만 적용.
- **Support-only:** 크기 제한 없이 editable 안만 현재 Q0로 교체. 밖은 base 유지.

| L256 사후 진단 | Raw AbsRel↓ | 경계 F1↑ | Flat-TV 상대 변화 | 품질 gate |
|---|---:|---:|---:|---|
| Bounded Q0 참조 | .159004 | .628963 | +6.011% | Flat 실패 |
| Support-only Q0 참조 | .159486 | .625379 | +10.335% | Flat 실패 |

L32도 두 진단 모두 flat-TV에 실패했다. 일부 위치를 현재 Q0에 더 가깝게 만드는 것만으로
전체 깊이장의 공간적 일관성과 GT 기반 품질 지표가 개선된다고 보장할 수 없다.
접합부 불연속이 가능한 원인이지만 이번에는 공간별 원인 분해까지 수행하지 않았다.
이 oracle은 GT metric의 최적해가 아니므로 **모든 국소 보정이 불가능하다는 증명도 아니다**.

## 6. 검증·결정·다음 우선순위

- 관련 테스트 **93 passed**.
- 전체 갱신2,560회에서 해당 dense Q0와 출력 차이0.
- 국소 적용 정책의 모든 생략 프레임에서 mask 밖 차이0 확인.
  별도 재계산 감사에서는 국소 학습/국소 적용의 mask 밖29,678,820개 픽셀을 저장된 기존 base와 비교해 동일함을 확인했다.
- Flow를 다시 계산해 얻은 base와 원래 저장된 output-flow도 정확히 일치했다.
- 주 실행/감사 source·Q0·training/development/cache/provenance hash 검증 완료.
- 기존 통과 후보, 원래 논문 모델·원고·최종 평가 결과는 수정하지 않았다.

**품질 보존 구현은 완료했으나 보정 이득은 미입증이므로, 새 CNN을 개선 모델로 채택하지 않는다.**
현재 기준 대조군은 여전히 보정 없는 output-flow K2다.

다음 우선순위는 픽셀별 깊이 교체보다 **필요한 프레임을 전체 Q0로 갱신하는 정책**의 비교다.

1. K2 출력-flow의 보존 경로를 유지하고, 더 생략해도 되는 프레임과 반드시 갱신할 프레임을 training 자료에서 구분한다.
2. RGB 불확실 면적 임계값만 사용하는 기존 보수적 정책은 가속에 실패했으므로 그대로 반복하지 않는다.
   학습형 갱신 정책과 고정 주기·비순환 대조를 동일 비용으로 비교한다.
3. SSM은 깊이값 수정 대신 갱신 필요성을 판단하는 시간 요약 역할에서 추가 이득이 있는지 검증할 수 있다.
   아직 구현·학습·우위 입증된 것은 아니다.
4. 정책 고정 뒤 독립 장면·실기기 검증으로 확대한다. 개발 gate를 완화하거나 기존 기기 로그를 새 모델 측정으로 대체하지 않는다.
