# SOKKANAEM: 효율적이고 안정적인 비디오 깊이 추정을 위한 정확한 변화 게이팅 상태공간 모델

> **작업 초안 — 2026년 7월 27일.** 저자·소속·학회 양식·인용·정성 그림·Jetson 실측은 추후 추가해야 한다. 아래의 정량 주장은 저장소에서 완료된 실험으로 범위를 제한한다.

## 초록

비디오 깊이 모델은 넓은 정적 영역을 프레임마다 반복 처리하며, 출력에 프레임 간 플리커가 발생하기 쉽다. 본 연구는 패치 수준 변화 감지를 선택적 상태공간 모델(SSM)의 이산화 단계에 연결한 소형 순환 비디오 깊이 모델 **SOKKANAEM**을 제안한다. 이진 활성 마스크 \(M\)이 주어질 때 SSM의 시간 간격 \(\Delta\)를 \(\widetilde{\Delta}=M\Delta\)로 대체한다. 정적 패치에서는 \(\widetilde{\Delta}=0\)이므로 \(\bar A=I\), \(\bar B=0\)이 되어 hidden state가 근사 복원되지 않고 정확히 복사된다. 시간축 SSM은 위치별 기억을 보존하고, 공간축 SSM과 dense decoder가 공간 문맥과 깊이를 복원한다. 이동 카메라에서는 저해상도 전역 모션 보정(GMC) 뒤에 피처 공간 변화 감지를 적용한다.

1,000클립 합성 홀드아웃에서 2.8M 파라미터 모델은 활성 패치 비율을 99.6%에서 24.0%로 줄이면서 AbsRel이 0.4166에서 0.4174로 상대 0.3%만 증가했고, 측정한 세 시간 오차는 모두 감소했다. 실촬·합성 혼합 파인튜닝 후 실내 RGB-D에서는 활성 17.9%에서 AbsRel 0.1789, \(\delta_1\) 0.7902를 기록해 풀 활성의 0.1772, 0.7953에 근접했다. 동일 활성률의 토큰 드롭 대조군은 크게 실패했다. 활성 31.6%에서 AbsRel은 1.7178로 \(\Delta\)-gating의 0.4292보다 4.0배 나빠, 보존된 state를 계속 읽는 것이 핵심임을 보였다. SOKKANAEM은 더 큰 세 베이스라인보다 원시 프레임 차이 오차가 크게 낮지만, 모션 보정 OPW나 GT 기준 TCE에서는 우위가 없다. 또한 정확한 state 스킵만으로 전체 연산량이 장면 변화율에 비례하지 않음을 보인다. 현재 구조에서는 dense readout과 decoder가 지배적이다. 이 결과는 정확한 변화 게이팅 state 보존의 유용성과 실제 효율을 달성하기 위해 필요한 커널·시스템 작업의 경계를 함께 제시한다.

## 1. 서론

단안 깊이 추정은 빠르게 발전했지만 이미지 모델을 비디오 각 프레임에 독립 적용하면 두 가지 구조적 비효율이 남는다. 첫째, 장면 대부분이 변하지 않아도 거의 고정된 비용으로 모든 프레임을 처리한다. 전경 움직임이 화면의 작은 일부만 차지하는 고정형 감시 카메라에서는 특히 낭비가 크다. 둘째, 실제 기하가 안정적이어도 독립 예측이 프레임마다 흔들릴 수 있다. 비디오 전용 모델은 시간 일관성을 높이지만 대체로 프레임 전체를 계속 계산하거나 별도의 시간 보정 단계를 추가한다.

본 연구는 더 구체적인 질문을 다룬다. **SSM이 ‘시각적 변화 없음’을 시간 기억에 대한 정확한 no-op으로 취급할 수 있는가?** 선택적 SSM의 영차 유지(zero-order hold) 이산화는 이를 직접 구성할 수 있게 한다. 시간 간격에 이진 패치 마스크를 곱하면 마스킹된 갱신은 hidden state에 대한 항등 사상이 된다. 따라서 정적 패치는 학습된 근사, 피처 보간, 별도의 시간 캐시 무효화 없이 기억을 유지한다.

이를 구현한 SOKKANAEM은 시간축·공간축 SSM 블록을 교차 배치한 스트리밍 비디오 깊이 구조다. 경량 변화 감지기는 hysteresis, dilation, 주기적 keyframe을 사용해 패치 활성 마스크를 만든다. 센서 없는 GMC와 피처 공간 감지기를 사용해 ego-motion으로 확장한다. 평가는 깊이 정확도와 원시 출력 변화뿐 아니라 광학흐름 워핑 일관성(OPW), GT 기준 시간 일관성 오차(TCE), 상수 출력 대조군, 해석적 MAC, 실측 지연시간을 함께 포함한다.

완료된 실험은 다음 네 결론을 지지한다.

1. **정확한 state 보존:** \(M=0\)일 때 \(\Delta\)-gating은 구현에서 bit-exact state 복사를, 수식에서 항등 전이를 만든다.
2. **양호한 희소성–정확도 절충:** 주 1,000클립 홀드아웃에서 활성률을 24.0%로 낮춰도 AbsRel은 상대 0.3%만 증가한다. 실촬 실내에서는 활성 17.9%에서 상대 AbsRel 열화가 1.0%다.
3. **보존 state의 readout이 중요:** 같은 마스크에서 \(\Delta\)-gating을 토큰 드롭으로 바꾸면 활성 31.6%에서 AbsRel이 4.0배 악화된다.
4. **효율 주장에는 명확한 경계가 있음:** 현재 모델에서는 state 갱신 경로만 활성률에 따라 줄어든다. dense projection, state readout, 공간 처리, decoder가 높은 연산 바닥을 만들므로 종단 비용은 아직 변화율에 비례하지 않는다.

본 연구는 시간 일관성 전반에서 항상 우월하다고 주장하지 않는다. SOKKANAEM은 플리커 중심 지표인 원시 프레임 차이에서는 가장 낮지만, 현재 평가에서 Depth Anything 3과 Video Depth Anything은 모션 보정 또는 GT 기준 지표가 더 우수하다.

## 2. 관련 연구

### 2.1 단안 및 비디오 깊이 추정

DPT와 Depth Anything 계열의 현대 단안 모델은 강한 프레임별 깊이를 제공하지만 스트림을 가로지르는 영속 state가 없다. 비디오 깊이 모델은 temporal attention, motion module, 후처리 등을 추가해 일관성을 높인다. 이들의 주목적은 예측 품질이며 공간·시간 계산은 대체로 dense하다. SOKKANAEM은 조건부 시간 state 갱신을 다루며 더 강한 사전학습 encoder나 decoder와 상보적이다.

### 2.2 동적 토큰 및 변화 기반 연산

토큰 pruning·merging·early exit는 단일 이미지 내부 연산을 줄인다. DeltaCNN, skip convolution, Eventful Transformer는 프레임 간 변화를 활용하지만 dense 출력을 유지하거나 복원하기 위해 피처 캐시와 캐시 정합성 규칙이 필요하다. SOKKANAEM은 변한 영역만 재계산한다는 원칙은 공유하되 시간 정보를 SSM hidden state에 저장한다. 토큰 드롭 ablation을 통해 정적 토큰을 단순 우회하는 것만으로 충분한지를 직접 검증하며, 결과는 충분하지 않음을 보인다.

### 2.3 시각 상태공간 모델

Vision SSM은 이차 복잡도의 attention을 선형 scan으로 대체하며 이미지와 비디오로 확장됐다. 표준 변형은 여전히 모든 토큰을 갱신한다. 본 연구의 기여는 외부에서 감지한 시각적 변화를 SSM 이산화 파라미터에 연결하고, 정확한 hidden-state 보존을 근사적인 공간 출력 캐싱과 구분한 것이다.

## 3. 방법

### 3.1 전체 구조

프레임 \(I_{t-1}\), \(I_t\)에 대해 모델은 다음을 수행한다.

1. 영상을 \(p\times p\) 패치로 분할한다. 완료된 주 실험에서는 \(p=16\)이다.
2. 이진 활성 마스크 \(M_t\)를 추정한다.
3. 현재 프레임을 패치 임베딩한다.
4. 시간축 \(\Delta\)-gated SSM과 공간축 SSM 블록을 교차 통과시킨다.
5. dense depth \(\widehat D_t\)를 복원한다.
6. 감지기 state와 패치별 SSM state를 다음 프레임으로 전달한다.

독립 state dictionary를 지원하므로 하나의 가중치 집합으로 여러 스트림을 state 누출 없이 처리할 수 있다.

### 3.2 패치 변화 감지기

기본 픽셀 감지기는 패치 \(i\)의 평균 제곱 변화를 계산한다.

\[
s_{t,i}=\frac{\lVert P_{t,i}-P_{t-1,i}\rVert_2^2}{p^2 C}.
\]

두 임계값으로 hysteresis를 구현한다.

\[
M_{t,i} =
\begin{cases}
1,&s_{t,i}>\tau_{\mathrm{on}},\\
0,&s_{t,i}<\tau_{\mathrm{off}},\\
M_{t-1,i},&\text{그 외}.
\end{cases}
\]

객체 경계를 보호하기 위해 활성 영역을 한 패치 팽창시키고, 드리프트를 제한하기 위해 \(K\)프레임마다 전체 갱신한다. 평가 전용 ablation에서 같은 활성률의 픽셀 MSE와 cosine 감지는 비슷해 MSE를 기본으로 유지했다. 완료된 3-arm 실험에서는 i.i.d. 랜덤 마스크 학습이 detector-driven 파인튜닝과 같거나 더 강건했다.

### 3.3 정확한 \(\Delta\)-gating

상태 행렬 \(A\), 입력 투영 \(B\), 시간 간격 \(\Delta_i\)를 갖는 연속 SSM을 영차 유지로 이산화하면

\[
\bar A_i=\exp(\Delta_i A), \qquad
\bar B_i=(\Delta_i A)^{-1}\left(\exp(\Delta_i A)-I\right)\Delta_i B,
\]

\[
h_i=\bar A_i h_{i-1}+\bar B_i x_i,\qquad
y_i=C_i h_i+D x_i
\]

가 된다. 활성 마스크를 시간 간격에 적용한다.

\[
\widetilde{\Delta}_i=M_i\Delta_i.
\]

\(M_i=0\)이면

\[
\bar A_i=I,\qquad \bar B_i=0,\qquad h_i=h_{i-1}.
\]

따라서 정적 패치의 state 전이는 정확한 항등이다. 다만 출력은 보존된 state를 \(C_i h_i\)를 통해 계속 읽을 수 있다. 이 구분은 \(\Delta\)-gating의 정확도와 연산량 바닥을 동시에 설명한다. 정확한 state 보존이 모든 정적 토큰 projection과 readout까지 제거할 수 있다는 뜻은 아니다.

### 3.4 시공간 백본

시간 블록은 각 공간 패치를 프레임 축으로 scan하므로 hidden state는 고정 영상 위치에 결합된 기억이 된다. 공간 블록은 프레임 내부 문맥을 혼합한다. 두 블록을 교차해 시간 지속성과 공간 추론을 결합한다. 완료된 v3/v7 모델은 차원 192, 4개 블록, state 차원 16, 파라미터 2.8M이다.

선택적 공간 출력 캐시는 활성 패치만 gather·갱신·scatter하고 정적 위치에는 이전 출력을 재사용한다. 시간 \(\Delta\)-gating과 달리 정적 공간 토큰이 새로운 문맥에 기여하지 않으므로 근사다. 현재 inference-only 구현에서는 활성률이 낮을 때만 유효하다.

### 3.5 이동 카메라 확장

카메라가 움직이면 원시 픽셀 차이가 화면 전체에서 발생한다. 저해상도 프레임에서 최대 50개 지점을 Lucas–Kanade로 추적하고 RANSAC으로 homography를 추정한다. 이전 프레임을 현재 시점으로 워핑한 뒤, 패치 임베딩 사이의 상대 \(L_1\) 차이로 활성 마스크를 만든다. 추정 실패 시 항등 변환으로 폴백하므로 변화를 잘못 억제하기보다 활성률이 증가한다.

Virtual KITTI 2에서 GMC+피처 게이팅은 활성 23.7%에서 풀 연산 대비 AbsRel이 상대 0.7%만 증가했다. 활성 2.3%에서도 AbsRel은 0.2054에서 0.2098로 증가하는 데 그쳤다. 이는 깨끗한 합성 ego-motion에서 메커니즘을 검증한 결과이며, 실제 노이즈가 있는 블랙박스 영상은 아직 평가하지 않았다.

### 3.6 Decoder와 학습 목적함수

보고된 체크포인트는 dense upsampling decoder를 사용한다. 학습 손실은

\[
\mathcal L =
\mathcal L_{\mathrm{SI-log}}
+0.5\mathcal L_{\mathrm{grad}}
+0.1\mathcal L_{\mathrm{temp}}
+0.05\mathcal L_{\mathrm{normal}}
\]

이다. 학습 중 랜덤 마스크 스케줄로 스킵률을 증가시킨다. 실패한 한 실행은 Kendall 방식 자동 손실 가중치를 사용했는데, 최적화가 시간 손실 가중치를 상한까지 높여 상수 깊이 출력이 최적이 됐다. 해당 체크포인트는 폐기하고 고정 가중치로 복귀했으며 예측 분산 기반 붕괴 감지기를 추가했다.

최근 학습 코드에는 클립 일관 증강, 다중스케일 DPT형 decoder, disparity 예측, 다중스케일 gradient loss가 추가됐다. 하지만 대응 장기 학습이 끝나지 않았으므로 주 결과의 구성요소로 주장하지 않는다.

## 4. 실험 설정

### 4.1 데이터

주 합성 학습 혼합은 Virtual KITTI 2, TartanAir v2, PointOdyssey로 구성한다. 데이터셋 균등 샘플링으로 가장 큰 소스의 독점을 막는다. 주 합성 홀드아웃은 8,929클립이며 모든 헤드라인 비교는 동일한 결정적 first 1,000클립을 사용한다.

배포 관련 실촬 도메인으로는 TUM RGB-D 고정 카메라 시퀀스와 Bonn RGB-D Dynamic을 사용한다. RGB와 depth는 20ms 이내 타임스탬프로 짝지었다. v7은 v3에서 시작해 실촬 2종과 합성 3종을 15k step 파인튜닝했다. 실촬 평가는 홀드아웃 488클립이며 합성 평가는 동일한 1,000클립 프로토콜을 유지한다.

초기 PoC는 128픽셀에서 Virtual KITTI 2 전체 42,520프레임, 학습 21,120클립, 최적화 30k step을 사용했다.

### 4.2 지표

평가 프로토콜의 클립별 스케일 정합 뒤 AbsRel, RMSE, \(\delta_1\)을 보고한다. 활성률은 감지기가 갱신하도록 허용한 패치 비율이다.

시간 지표는 다음과 같다.

- **t-delta:** 인접 프레임 출력의 평균 차이. 원시 플리커를 재지만 상수 출력이 최솟값이다.
- **OPW:** RAFT-small 광학흐름으로 예측을 워핑한 오차다.
- **TCE:** 예측의 워핑 잔차와 GT 자체 워핑 잔차의 차이다. GT 기하가 변할 때 상수 예측을 벌점한다.

완전한 시간 표에는 클립별 최적 상수 깊이 대조군을 함께 둔다. 이 대조군은 t-delta와 OPW의 퇴화를 드러내고 TCE의 데이터셋 고유 잔차 바닥을 제공한다.

### 4.3 베이스라인과 구현

동일 1,000클립과 공통 지표 구현으로 Depth Anything V2 Small(24.8M), Depth Anything 3 Base(120M), Video Depth Anything Small metric(28.4M)과 비교한다. SOKKANAEM은 2.8M 파라미터다. 지연시간은 RTX 4090, batch 1에서 측정하고 MAC은 설정에서 해석적으로 계산한다. Jetson 결과는 아직 없다.

### 5.4 정확한 state readout이 중요한 이유

같은 감지기와 마스크를 사용하는 \(\Delta\)-gating과 토큰 드롭을 비교한다. 두 방법 모두 정적 위치의 hidden state는 동결하지만, 토큰 드롭은 보존 state를 읽지 않고 시간 블록 출력을 우회한다.

**표 4. 1,000클립 게이팅 위치 ablation.**

| 활성률(%) | 방법 | AbsRel | \(\delta_1\) | t-delta | OPW | TCE |
|---:|---|---:|---:|---:|---:|---:|
| 48.6 | \(\Delta\)-gating | 0.4288 | 0.5276 | 0.2573 | 0.0544 | 0.0882 |
| 48.6 | 토큰 드롭 | 1.3698 | 0.1658 | 7.1374 | 0.5337 | 0.5680 |
| 31.6 | \(\Delta\)-gating | **0.4292** | **0.5285** | **0.2455** | **0.0541** | **0.0879** |
| 31.6 | 토큰 드롭 | 1.7178 | 0.1424 | 7.1692 | 0.8252 | 0.8579 |
| 24.0 | \(\Delta\)-gating | 0.4301 | 0.5282 | 0.2421 | 0.0540 | 0.0878 |
| 24.0 | 토큰 드롭 | 1.8727 | 0.1365 | 7.2018 | 0.9285 | 0.9597 |

활성 31.6%에서 토큰 드롭은 \(\Delta\)-gating보다 AbsRel이 4.0배, t-delta가 29배 나쁘다. 이 실험은 이득의 원인을 분리한다. 스킵이 정확한 이유는 정적 토큰을 대체 없이 제거할 수 있어서가 아니라 보존된 state를 계속 읽기 때문이다.

### 5.5 이동 카메라 PoC

128픽셀 Virtual KITTI 2에서 픽셀 게이팅은 활성 44.6%에서 AbsRel 0.2057을 기록해 풀 활성 0.2054와 거의 같다. GMC+피처 게이팅은 활성 23.7%에서 0.2068, 활성 2.3%에서 0.2098이다. 원시 시간 차이는 풀 연산 0.1033에서 가장 공격적인 GMC 설정 0.0762까지 단조 감소한다. 이 저해상도 설정에서 GMC 오버헤드는 약 0.8ms/frame이다.

### 5.6 연산량 및 wall-clock 분석

초기 구현은 Python 순차 scan을 사용했다. 이를 chunk segment-sum scan으로 바꾸자 128픽셀 처리량이 104에서 372 FPS로 증가했고, 512픽셀 지연시간은 137ms에서 19ms로 줄었다. 풀 연산 경로를 compile하면 128픽셀 1,075 FPS, 256픽셀 366 FPS에 도달했다. 256픽셀에서 SOKKANAEM은 compile 풀 연산 366 FPS, 정적 스트림 캐시 460 FPS이며 비교한 경량 베이스라인은 280–380 FPS였다.

이 속도 향상은 scan 재구성, graph capture, caching에서 왔으며 \(\Delta\)-gating 자체의 결과가 아니다. 256픽셀 v3의 해석적 회계는 2.337 GMAC/frame이다.

| 활성률(%) | \(\Delta\)-gating만 | 풀 연산 대비 | +공간 캐시 | 풀 연산 대비 |
|---:|---:|---:|---:|---:|
| 100 | 2.337 | 100.0% | 2.337 | 100.0% |
| 16.6 | 2.266 | 97.0% | 1.842 | 78.8% |
| 0 | 2.252 | 96.4% | 1.743 | 74.6% |

decoder가 MAC의 67.8%를 차지하며, 정적 시간 토큰도 projection과 readout이 남아 활성 토큰 블록 비용의 58.5%를 지불한다. 제안된 v6 shuffle decoder와 학습된 sparse spatial 경로는 활성 16.6%에서 38.6% 비용을 투영하지만, 비교 가능한 학습이 완료되지 않았으므로 실측 결과가 아니다.

## 6. Ablation과 진단 결과

### 6.1 마스크 정책

같은 활성률에서 MSE와 cosine 변화 점수는 비슷하다. 시험한 keyframe 간격은 짧은 클립 정확도에 거의 영향을 주지 않는다. i.i.d. 랜덤 마스크로 학습한 모델이 detector-driven 마스크 파인튜닝보다 더 강건했으며, 이는 학습·배포 마스크 분포 일치가 필수라는 초기 예상과 반대다.

### 6.2 DINOv2 피처 증류

최종 백본 토큰을 frozen DINOv2-small 피처와 맞춰도 깊이 정확도는 개선되지 않는다. v4 AbsRel은 0.4315로 v3 0.4292보다 나쁘다. 다만 TCE는 0.0846 대 0.0879로 소폭 좋아져, 기하 표현 개선보다 정규화 효과로 해석된다.

### 6.3 정확도 병목

패치 그리드 oracle에서 16픽셀 depth decoder의 잠재 상한은 AbsRel 0.1746, \(\delta_1\) 0.8542로 현재 합성 홀드아웃보다 훨씬 높다. 학습에 사용한 클립에서 v7은 AbsRel 0.1918, \(\delta_1\) 0.7074에 도달하지만 진단용 미학습 클립에서는 0.3562, 0.5185다. 따라서 현재 즉각적인 병목은 용량이나 명목 해상도가 아니라 장면 간 일반화다.

소스별 분석은 TartanAir의 매우 넓은 0.5–129m 깊이 범위와 PointOdyssey의 train–holdout 격차를 주요 원인으로 지목한다. 이에 disparity 공간 예측, 클립 일관 증강, 다중스케일 decoder를 도입했지만 최종 결과는 아직 진행 중이다.

## 7. 한계

현재 연구에는 다음과 같은 중요한 한계가 있다.

1. 외부 베이스라인 표는 v3 체크포인트를 사용한다. v7은 같은 합성 데이터 프로토콜로 별도 재실행했지만 모든 외부 베이스라인과 하나의 결합 실행으로 다시 평가하지는 않았다.
2. 실촬 실내 v7 평가에서는 시간 지표가 NaN으로 기록되어 t-delta, OPW, TCE를 보고하지 못한다. 표 2로부터 시간 관련 주장을 하지 않는다.
3. OPW와 TCE는 시간 일관성 전반의 우위를 지지하지 않는다. 원시 t-delta는 상수 예측으로 조작할 수 있으므로 정확도와 상수 대조군을 함께 읽어야 한다.
4. 현재 dense decoder와 state readout이 높은 연산 바닥을 만든다. 실질적 희소 가속을 위해 학습된 공간 희소 경로와 전용 block-sparse kernel이 필요하다.
5. RTX 4090 실행은 kernel launch-bound이므로 해석적 MAC 감소가 자동으로 FPS 증가가 되지 않는다. Jetson Orin 지연시간·에너지·멀티스트림 실측은 수행하지 않았다.
6. GMC는 깨끗한 합성 ego-motion에서 검증했으며 실제 이동 카메라 노이즈에서는 미검증이다.
7. 드리프트 분석은 최대 270프레임 스트림까지만 수행했다. 매우 긴 스트리밍 동작은 알 수 없다.
8. 패치 크기, refinement, 완전 학습된 decoder/cache ablation은 완료되지 않았다.

## 8. 결론

SOKKANAEM은 패치 수준 시각 변화가 SSM의 이산화 단계를 제어하도록 해 정적 관측을 시간 state에 대한 정확한 항등 전이로 만들 수 있음을 보였다. 합성 및 실촬 RGB-D 평가에서 공격적인 패치 희소화가 깊이 정확도를 거의 해치지 않았고, 동일 마스크 토큰 드롭 대조군은 보존 state를 계속 읽는 것이 핵심임을 확인했다. 이 모델은 비교한 깊이 베이스라인보다 훨씬 작으면서 원시 프레임 간 플리커를 강하게 억제한다.

동시에 실험은 아이디어의 경계를 드러낸다. 정확한 state 스킵이 곧 종단 희소 추론을 뜻하지는 않는다. dense readout, 공간 문맥, decoder가 남는다. 낮은 원시 프레임 변화가 모션을 올바르게 따르는 시간 정확도를 보장하지도 않는다. 따라서 다음 핵심 단계는 학습된 sparse spatial 경로, 경량 다중스케일 decoder, block-sparse GPU kernel, 실촬 이동 카메라 평가, 에지 장치 실측이다. 이 범위 안에서 정확한 \(\Delta\)-gating은 변화 적응형 스트리밍 비전의 원리적 기반을 제공한다.
