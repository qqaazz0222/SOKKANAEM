# 모델 중심 논문 개정 — 2026-09-08

현재 제목: **SOKKANAEM: Change-Gated State-Space Modeling with Cached Readout for Streaming Video Depth**.
논문의 주인공을 조건부 오차 분석에서 SOKKANAEM 구조·설계·실험으로 변경했다.
이는 **원고 구조 및 기존 증거의 재편**이다. 새 모델 학습이나 성능 개선의 완료를 의미하지 않는다.

## 원고에 반영한 사항

| 구성 | 개정 내용 |
|---|---|
| 제목·초록·서론 | 경량 스트리밍 깊이 모델의 문제 설정, 설계, 검증 결과를 먼저 설명 |
| 제안 방법 | 변화량/히스테리시스/강제 갱신, temporal state와 readout, spatial cache, dense decoder, 스트리밍 순서 및 학습 설정 확장 |
| 모델 기여 검증 | 기존 동일 가중치·동일 마스크 개발 ablation 7개를 본문 표로 복원 |
| 수학 분석 | 독립적인 주기여보다 설계 근거로 배치; 가정·반례·증명은 보존 |
| 정확도·안정성·속도 | 기존 동결 평가 유지, 유리/불리한 결과 모두 보고; 미검증 성능을 새 주장으로 추가하지 않음 |
| 결론 | SOKKANAEM의 설계와 관측된 trade-off, 다음 모델 개선 목표로 정리 |

현재 K30·가중치·데이터 계약·평가식·원시 점수는 변경하지 않았다.
복원된 ablation은 개발 13×256프레임, source-balanced pixel-pooled clip scale–shift 결과다.
부분 Linear/Conv GMAC은 전체 FLOPs나 실측 시간으로 해석하지 않는다.
기존 R3 대응표의 통계·출처 정정은 유효하다. 제목/절 이름에 대한 R3 문구는 개정 전 기록이다.

## 더 빠르고 안정적인 모델을 실제로 입증하기 위한 다음 단계

1. **개발 기준 고정:** 이미 개봉한 final을 untouched라고 재사용하지 않는다.
   새 모델 선택은 개발 데이터에서 하고, 신규 평가 집합과 허용 정확도 저하 범위는
   새 실험 전에 정한다. 정확도 동등성 허용폭을 사후로 정하지 않는다.
2. **비용 개선:** 입력 read/decode/preprocess와 희소 gather/cache 비용을 따로 개선한다.
   경계를 달리한 GPU-resident 측정과 end-to-end 측정은 구분한다.
3. **안정성 개선:** 누적 변화·캐시 사용 기간을 반영한 선택적 갱신을 후보로 검증한다.
   이는 제안된 개발 가설이며 현재 v11에서 구현·검증된 신기법이라고 쓰지 않는다.
4. **동일 조건 비교:** dense carry/reset, output hold, 경량 이미지 모델 및 온라인 비디오 모델.
   AbsRel/GT 기준 시간 오차/scale 변동/latency·tail/메모리/에너지를 함께 평가한다.
5. **엣지 검증:** Nano B01 5W/10W의 실영상·현 가중치·코드·전력 기록을 연결한다.
   기존 합성 실측은 보조 근거이며 새로운 실영상 가속 결과를 대신하지 않는다.

독립적인 수학·신규성 검토, 저자 승인, 연구비/공개 정보/권리 확인은 계속 필요하다.
본 개정은 연구 방향을 모델 중심으로 전환하지만, 목표 성능 달성이나 투고 준비 완료를 선언하지 않는다.
