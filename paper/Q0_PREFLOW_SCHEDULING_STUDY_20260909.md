# 흐름 계산 전 RGB 기반 Q0 갱신 판단

2026-09-09. [학습형 갱신 정책](Q0_LEARNED_SCHEDULING_STUDY_20260909.md)의 비용 병목 후속 실험.

**RGB-only MLP q50이 두 개발 구간과 한 프레임 시작점 변경에서 품질 gate를 통과했다.
3회 반복에서 L256 평균 3.762ms, Q0 대비 1.997×, 기존 K2 대비 시간 13.73% 감소였다.**
추가 검증 후보로 보존한다. SSM 고유 이득이나 독립 검증 성공을 뜻하지 않으며 논문 모델 승격은 보류한다.

## 변경 범위와 대조

이전 정책은 재사용을 거절하는 프레임에서도 흐름과 후보 깊이 통계를 먼저 계산했다.
이번에는 현재/anchor RGB 통계와 캐시 나이만으로 먼저 결정하고, 실제 재사용할 때만 흐름을 계산한다.
깊이 보정은 없으며 생략 출력은 이전 깊이의 nearest 흐름 이동이다. 전체 갱신은 원래 Q0 그대로다.
첫 생략은 필수, gap2/3은 학습 판단, gap4는 전체 갱신하는 규칙도 유지했다.

- 기존 20개 입력 중 RGB/나이 14개만 사용하고 흐름 관련 6개는 0으로 고정했다.
  구조 통제를 위해 입력 크기를 유지했다. 이에 해당하는 입력 가중치 96개는 데이터 gradient가 없다.
- Carry SSM / 매 입력 상태 초기화 SSM / MLP: 각각 1,689 / 1,689 / 1,688파라미터.
  동일 공통 초기화, seed741, 정확히 같은 batch 순서, 각 1,000step, batch32, AdamW lr.001.
- 기존 training 192개 4프레임 클립의 fit144 / 임계값 설정48 분할을 유지했다.
  Fit288 trace와 설정용96 trace, 설정용 gap2/3 관측144개를 사용했다.
- 위험 라벨은 기존 Q0 log-depth L1 + 2×다중 스케일 log-gradient L1 그대로다.
  비용·입력 변경 효과를 분리하기 위해 GT 경계/평탄 영역 손실을 추가하지 않았다.
- 모델별 설정용 **예측값**의 q25/50/75를 개발 평가 전에 저장했다. 확률적 위험 보장은 아니다.
- 동일 Carry 가중치와 임계값을 흐름 계산 전/후에 실행했다. 두 실행의 출력과 갱신 순서가
  같아야 하는 대조다. 기존 20입력 정책과의 비교에는 입력 제거·재학습 효과도 섞여 있다.

| 모델 | q25 | q50 | q75 | 설정용 위험 MAE |
|---|---:|---:|---:|---:|
| Carry SSM | .032186 | .058684 | .071836 | .017032 |
| Reset SSM | .030378 | .059185 | .073794 | .016764 |
| MLP | .030539 | .053275 | .071257 | .016545 |

## 첫 개발 평가

기존 Q0 상대 품질 gate를 변경하지 않았다: raw/edge AbsRel·overshoot·flat-TV 각 +1% 이내,
경계 F1 감소 ≤.005, source별 raw AbsRel +2% 이내를 모두 요구한다.
L32 256프레임과 L256 1,024프레임은 **재사용한 개발 자료**이며 독립 장면 검증이 아니다.

| 정책 | L32 품질 | L256 품질 | L256 생략률 | L256 평균 ms |
|---|---|---|---:|---:|
| Q0 dense | 기준 | 기준 | 0% | 7.535 |
| 기존 출력-flow K2 | 통과 | 통과 | 50.00% | 4.390 |
| 출력-flow K4 | edge 실패 | edge·flat 실패 | 75.00% | 2.692 |
| Carry q25 | 통과 | 통과 | 53.03% | 4.508 |
| Carry q50 | edge 실패 | 통과 | 64.55% | 3.706 |
| Carry q75 | 통과 | edge·source 실패 | 69.92% | 3.315 |
| Reset q25 | 통과 | 통과 | 52.93% | 4.508 |
| Reset q50 | flat 실패 | 통과 | 63.09% | 3.795 |
| Reset q75 | edge 실패 | edge 실패 | 69.82% | 3.325 |
| MLP q25 | 통과 | 통과 | 53.22% | 4.371 |
| MLP q50 | 통과 | 통과 | 61.72% | 3.791 |
| MLP q75 | raw·edge·flat·source 실패 | raw·edge 실패 | 69.63% | 3.237 |

시간은 공유 RTX4090에서 GPU 상주 입력으로 프레임별 동기화한 벽시계 시간이다.
정책·CPU 흐름·내부 전송·Q0 실행은 포함하고 최초 파일 읽기/입력 H2D는 제외했다.
단일 평가 표이며 반복 측정은 아래 추가 검증에 별도로 기록한다. Nano/Pi 측정이 아니다.

MLP q50의 원래 시작 시점 품질은 다음과 같다. 생략률 증가가 정확도 전반의 향상을 뜻하지 않는다.

| 구간/모델 | Raw AbsRel | Edge AbsRel | 경계 F1 | Q0 대비 flat-TV |
|---|---:|---:|---:|---:|
| L32 Q0 | .128127 | .159325 | .660219 | 기준 |
| L32 MLP q50 | .128377 | .160155 | .661137 | +.715% |
| L256 Q0 | .159183 | .174237 | .614665 | 기준 |
| L256 MLP q50 | .159336 | .174666 | .621973 | +.963% |

L256 flat-TV 증가의 허용 여유는 약 .037%p뿐이다. 반올림 전 값으로 판정했다.
MLP 후보를 선택한 것은 개발 결과를 본 뒤이므로 후속 반복도 독립적인 모델 선택 검증은 아니다.

## 비용 제거와 실행 감사

동일 Carry q25의 L256 실행에서 판단을 앞으로 옮기면 흐름 계산 횟수가 1,990→1,086회로 줄었다.
재사용 거절 452프레임에서 양방향 흐름 904회를 피한 결과다. 단일 측정 평균은 4.895→4.508ms였다.
이는 **같은 RGB 정책의 계산 순서 대조**이며, SSM 기억이나 품질 개선의 증거는 아니다.

- Carry q25/50/75 전/후 실행: 전체 3,840프레임 출력 bitwise 일치, 갱신 순서 일치.
- 모든 최초 평가 정책의 전체 갱신 6,759프레임: Q0 출력과 정확히 일치.
- 별도 감사에서 학습 정책의 생략 출력 9,561프레임을 흐름부터 다시 계산하여 정확히 일치 확인.
- 설정용 예측 분위수를 세 모델 모두 재계산하여 저장 임계값과 정확히 일치 확인.
- 모든 판단의 gap·임계값·흐름 호출 수를 검사했다. 사전 판단의 재사용 거절 프레임은 흐름 호출 0회다.
- 관련 단위/회귀 테스트 98개 통과. 실험 코드·부모 기록·입력 hash 불변 확인.

## 반복 측정과 시작점 변경

개발 평가 이후 MLP q50을 선택하고 임계값·가중치는 그대로 유지했다.
첫 두 프레임을 Q0로 계산한 다음 원래 정책을 시작하는 한 프레임 초기화 이동을 평가했다.
이는 모든 시작점에 대한 강건성 검증은 아니다.

| 시작점 변경 | Raw AbsRel | Edge AbsRel | 경계 F1 | Q0 대비 flat-TV | 품질 gate |
|---|---:|---:|---:|---:|---|
| L32 | .127773 | .160188 | .663258 | +.309% | 통과 |
| L256 | .159334 | .174671 | .621707 | +.921% | 통과 |

변경 실행의 전체 갱신 497프레임도 Q0와 정확히 일치했다. 최초 평가와 합하면 7,256회다.
다음 시간은 원래 시작점의 64프레임 warmup 후 모델 실행 순서를 회전한 3회 반복 평균이다.

| 구간 | Q0 ms | K2 ms | MLP q50 ms | MLP 지연 판단 ms | Q0 대비 배속 | K2 대비 시간 감소 |
|---|---:|---:|---:|---:|---:|---:|
| L32 | 7.491 | 4.348 | 3.720 | 3.931 | 2.014× | 14.45% |
| L256 | 7.512 | 4.360 | 3.762 | 4.026 | 1.997× | 13.73% |

MLP 사전 판단의 반복 평균 범위는 L32 3.716–3.728ms, L256 3.760–3.765ms다.
공유 GPU 반복값이며 신뢰구간·독립 하드웨어 검증이나 실시간 입력 처리량 측정으로 해석하지 않는다.
지연 판단은 같은 MLP를 흐름 계산 뒤에 실행한 비용 대조이며, 출력 bitwise 대조 집계 3,840회는
앞 절의 Carry 정책에 한정한다. 모든 감사의 기록 hash 불변을 마지막에도 확인했다.

## 판단과 다음 우선순위

1. MLP q50은 **개발 단계에서 품질 허용 범위를 지키면서 K2보다 빠른 후보**로 보존한다.
   전체 프레임 정확도·경계·선명도를 동시에 향상시킨 모델이라는 주장은 하지 않는다.
2. SSM은 이번에도 두 구간 품질과 K2 대비 추가 속도를 함께 만족하는 우위를 입증하지 못했다.
   MLP 결과를 SSM 기억의 기여로 원고에 사용하지 않는다. 변화 기반 선택적 재계산의 효과로만 구분한다.
3. 다음은 정책을 고정하고 **기존 선택에 사용하지 않은 비-final 개발 장면**에서 검증하는 것이다.
   자료 분할을 먼저 감사하고, 여러 시작점·장면별 결과와 flat-TV의 작은 여유를 확인해야 한다.
   이 결과를 보고 같은 검증 자료에 임계값을 반복 최적화해서는 안 된다.
4. 그다음 다중 seed, 위험 목표와 실제 경계/flat 실패의 대응 분석, Nano B01 5W/10W·Pi4 실측이다.
   실제 장치 접속·실측 자료 없이 GPU 배속을 엣지 성능으로 환산하지 않는다.
