# RGB 흐름을 SOKKANAEM 특징 캐시·SSM에 결합한 대조 실험

후속: [정렬 특징 SSM·MLP 동등 예산 학습](Q0_ALIGNED_TRAINING_STUDY_20260909.md).
새 학습 두 후보는 경계 gate에 실패했다. 아래 동결 결합 후보의 통과 기록과 구분한다.

2026-09-09. [출력 깊이 이동 실험](Q0_RGB_FLOW_STUDY_20260909.md)의 후속.

**Nearest 특징 이동+SSM 후보가 L32/L256의 기존 품질·가속 기준을 통과했다.**
그러나 같은 특징 이동에서 SSM 업데이트를 제거한 대조군도 통과하며, SSM 추가 시
raw/경계F1이 개선되지 않았다. 따라서 **결합 구현·개발 기준 통과는 확인했지만 SSM의 추가 우위는 미입증**이다.
SSM 없는 출력 깊이 이동이 현재는 더 빠르고 경계도 더 좋다. 논문 모델은 교체하지 않았다.

## 1. 이번에 실제로 바꾼 것

- 이전 단계와 같은 DIS ULTRAFAST 양방향 RGB 흐름을 사용한다. 128px 흐름을 Q0의37×37 특징 격자 단위로 변환한다.
- 네 단계의 patch feature와 SSM h를 함께 이동한다. CLS/pooled는 이동하지 않는다.
- Nearest/bilinear 보간 × SSM update on/off의2×2 비교를 수행한다.
- 같은 동결 Q0와 `qquality_feature_20260908/adapter.pt`를 모든 조건에서 공유한다.
  Post-encoder CLS delta와 raw pooled delta를 쓰지 않는 `SeparatedDelta(True, True)`다.
- 변화 검출은 기존 RGB patch MSE threshold .001/.0005 및 dilation을 그대로 쓴다.
  이 검출 mask는 흐름 정렬 후 RGB 잔차가 아니라 기존 anchor와의 차이다. Flow 신뢰도에 의한 픽셀 혼합은 하지 않는다.
- 전체 갱신에서는 원래 Q0를 실행하고, 생략 시 이동된 특징에 선택적 SSM update를 적용한 뒤 Q0 decoder를 실행한다.
- 비교군은 출력 깊이 nearest 이동 및 기존 비정렬 SSM K2다. 추가 학습은 없다.
  기존 adapter는 이번 DIS 정렬 특징으로 학습되지 않았으므로 분포 변화의 한계가 있다.
- K2 전체 갱신에서 h를0으로 초기화하므로 생략 직전 h도0이다.
  h 이동 코드는 구현·검사했지만 이번 주기의 성과를 장기 temporal memory 기여로 해석하지 않는다.

## 2. L256 정량 결과

| 구성 | Raw AbsRel↓ | 경계 F1↑ | Flat-TV 상대 변화 | 평균 ms | 개발 동시 gate |
|---|---:|---:|---:|---:|---|
| Q0 dense | .159183 | .614665 | 기준 | 7.542 | 기준 |
| 출력 깊이 nearest 이동, SSM 없음 | .159120 | .620225 | +0.852% | 4.383 | 통과 |
| 기존 비정렬 SSM K2 | .159216 | .611583 | +1.513% | 4.847 | Flat-TV 실패 |
| Nearest 특징 이동, SSM update 없음 | .159719 | .610922 | +0.972% | 5.271 | 통과 |
| **Nearest 특징 이동 + SSM** | **.159725** | **.610411** | **+0.889%** | **5.537** | **통과** |
| Bilinear 특징 이동, SSM update 없음 | .159559 | .600770 | −1.455% | 5.281 | 경계 실패 |
| Bilinear 특징 이동 + SSM | .159589 | .599994 | −1.504% | 5.549 | 경계 실패 |

SSM 결합 후보는 dense 대비약1.362×, 평균 시간약26.6% 감소다. 이 표는 단일 평가값이며
출력 이동 보고서의3회 반복1.724×와 반복 수준을 혼동하지 않는다. 작은 지연 차이에 통계적 의미를 부여하지 않는다.
모든 시간은 GPU-resident 입력에서 동기화한 호출 시간으로, CPU 흐름·내부 전송·특징 이동·SSM·decoder 비용을 포함한다.
최초 IO/H2D와 동영상 decode는 제외하며 RTX4090 결과이지 Nano/Pi 실측이 아니다.

SSM 결합의 source raw 변화는 TUM−.825%, Bonn+1.306%로+2% 제한 내다.
경계F1 허용 하한은 .609665이며 실제 .610411로 여유가 약.000746이다.
Flat-TV도+1% 허용치에 가깝다. 품질 보존은 모든 출력이 Q0와 같다는 뜻이 아니다.

L32에서는 nearest 특징 이동(SSM on/off) 모두 통과한다.
SSM on의 raw .128428, F1 .659964, flat-TV−1.371%, 평균5.540ms였다.
Bilinear 두 구성은 L32도 경계 gate를 통과하지 못했다.

## 3. 무엇이 기여했는가

같은 nearest 특징 이동에서 SSM을 켜면 L256에서:

- Raw .159719→.159725: 아주 소폭 악화.
- 경계F1 .610922→.610411: 악화.
- Flat-TV 상대 증가+.972%→+.889%: 소폭 개선.
- 평균 시간5.271→5.537ms: 증가.

즉 일부 거칠기 지표를 줄였지만 전반적인 품질·비용 우위는 확인하지 못했다.
기존 비정렬 SSM 대비 기준 통과가 가능해진 것을 SSM만의 성과로 주장해서는 안 된다.

실제 첫 단계 특징 값이 이동으로 달라진 patch 비율은 생략 프레임 평균 L32 3.90%, L256 18.82%였다.
최근접37×37 이동은 작은 sub-token 움직임을 반올림해 무이동으로 만들 수 있다.
이 수치는 실제 대응 정답 일치율이 아니라 특징 값 변화 비율이다.
SSM은 생략 프레임마다 평균 L32 974.3/1369개, L256 1061.2/1369개 patch를 업데이트했다.
즉 모듈이 완전히 꺼져 있어서 효과가 없었던 것은 아니다.

RGB의 기하학적 이동이 전역 문맥을 가진 encoder 특징의 정확한 이동을 보장하지는 않는다.
출력 이동과 특징 이동의 차이에는 격자 해상도와 decoder 재실행도 함께 들어 있으므로
이번 대조만으로 특정 하나를 원인으로 확정하지 않는다.

## 4. 검증과 결정

- 관련 회귀 테스트 **84 passed**.
- 신규 테스트에서 patch/h 동일 방향 이동,0이동 동일성, CLS/pooled 보존, 호출자 cache 비변경 확인.
- 이번6개 정책×L32/L256의 전체 갱신3840회에서 dense Q0와 출력 차이0 확인.
- 실행 source·Q0·adapter·개발 데이터 hash 계약 재검사 통과.
- 출력 nearest 대조의 저장된 정량 결과는 직전 연구와 동일하게 재현됐다.
- Training/final에 대한 새 쓰기, 가중치 변경, 기존 논문 원고/최종 결과 교체는 하지 않았다.

현 상태에서는 출력 nearest를 강한 대조군으로 유지하고, 결합 후보는 추가 연구용으로 남긴다.
다음 우선순위는 **정렬된 특징에 맞춘 training-only 학습과 SSM 고유 기여 대조**다.

1. 같은 자료·학습 예산에서 정렬 특징 adapter와 비순환/SSM 제거 대조를 학습한다.
   출력-flow 기준도 반드시 유지한다. Dev gate를 완화하지 않는다.
2. h가 실제로 다음 생략 프레임까지 전달되는 조건에서 state 유지/제거를 같은 가중치로 비교한다.
   현재 K2 reset 결과를 장기 기억 기여로 대신하지 않는다.
3. 후보 고정 후 새 개발 장면·가림/빠른 움직임·위상/주기·시간 일관성 검증으로 확대한다.
4. 독립 검증 전 원고 성능표 승격을 보류하고, 사용자 장치 접속/실행 가능 시 별도5W·10W 전력 경로를 측정한다.
