# 고정 시점 적용 범위 — 2026-09-10 확정

## 연구 질문

고정된 카메라가 촬영하는 동적 영상에서, 사전학습 깊이 모델의 출력 품질을 명시한 허용 범위 안에서 유지하면서 선택적 재추론으로 처리 비용을 줄일 수 있는가?

주 방법은 **SOKKANAEM-Refresh: 고정 시점 영상용 선택적 깊이 갱신 파이프라인**이다.
범용 깊이 백본, 입증된 SSM 기억 우위, 안전 보장 시스템을 주장하지 않는다.

## 포함·제외 조건

- 주 적용 범위: 설치 위치·방향·초점거리가 유지되는 고정 장착 카메라, 현재 단계에서는 실내 영상.
- 움직이는 사람·물체, 물체 진입/퇴장, 가림/드러남, 빠른 동작은 **범위 안의 검증 대상**이다. 어려운 물체 움직임을 이유로 제외하지 않는다.
- 미세 진동은 별도 준고정 민감도 조건이다. 고정 장착 여부와 잔여 움직임을 기록하고 순수 고정 조건과 합쳐 보고하지 않는다.
- 범위 밖: 의도적인 카메라 이동·회전, PTZ/줌 조작, 카메라 재설치. 해당 상황의 기존 결과는 스트레스 테스트로 보존한다.
- 편집 컷/입력 재연결은 새 스트림으로 초기화해야 하는 운용 조건이다. 자동 감지와 즉시 갱신은 아직 구현·검증된 기능으로 주장하지 않는다.
- 일반 RGB만으로 추론한다. 정확도 검증에는 동기화된 깊이 정답이 필요하다. GT 없이 Q0와 비슷하다는 사실은 실제 정확도 검증이 아니다.

## 사후 범위 변경의 투명성

이 범위는 Freiburg1 room/Freiburg2 desk 검증의 실패를 확인한 **뒤에** 사용자와 확정했다.
따라서 과거 실험을 처음부터 고정 카메라 연구였다고 소급해서 표현하지 않는다.
해당 검증의 L32 오버슈트 +2.285% 실패를 삭제하지 않으며, 이동 카메라 스트레스 결과로 유지한다.
기존 네 개발 시퀀스 전체를 고정 카메라 성능으로 재명명하지 않는다.

## 현재 후보와 검증 계약

- 기존 `frozen_candidate.json`의 Q0 및 MLP q50 가중치와 임계값은 변경하지 않는다.
- 전체 프레임 갱신을 선택하는 모델이다. 움직이는 영역만 Q0를 실행하는 공간 부분 추론 모델이 아니다.
- 기존 raw/edge AbsRel·overshoot·flat-TV +1%, F1 감소≤.005, source raw +2% 기준은 유지한다.
- 새로운 주 검증은 고정 설치가 확인되고 학습/선택에 쓰이지 않은 별도 장소의 시퀀스에서 시행해야 한다.
- 실제 시험 목록과 시작 위치는 예측 전에 확정한다. 실패 구간을 제거하거나 해당 시험 결과로 임계값을 조정하지 않는다.
- 비교: Q0 dense, 단순 output hold, fixed K2 flow, frozen learned refresh. 추가 제어의 비용과 출력 정의를 먼저 고정한다.
- 전체 평균 외에 장소별·동적 영역·경계·가림 해제 영역을 보고한다. 동적/가림 마스크가 proxy라면 정답 마스크로 부르지 않는다.

## 카메라 움직임 감사 규칙

`groundtruth.txt`의 timestamp/translation/quaternion을 사용한다. RGB 시각에 50ms 이내 최근접 pose를 연결한다.
첫 유효 pose 기준 translation/rotation의 p95와 최대값, pose 대응률을 보고한다. Quaternion 부호는 동일 회전으로 처리한다.
대응률≥95%, p95 translation≤0.02m 및 p95 rotation≤1degree를 **저움직임 선별 진단**으로만 표시한다.
이 숫자는 장착 고정의 증명이나 깊이 오류 보장이 아니며, 품질 결과에 맞춰 고른 임계값도 아니다.
장착 근거가 없는 영상은 pose가 작아도 `fixed_mount_verified`로 판정하지 않는다.
시퀀스명에 static이 있다는 이유만으로 고정 카메라로 분류하지 않는다.

## 실시간 주장

목표 운용점은 30fps 입력이다. 아직 충족했다고 주장하지 않는다.
캡처/디코드·전처리·전송·정책·흐름·Q0·출력 반환을 포함하는 경계를 명시하고,
평균/p95 지연, 33.3ms 프레임 예산 초과율, 지연 누적/드롭 프레임을 실제 목표 기기에서 측정한다.
RTX4090의 GPU 상주 입력 시간과 Nano B01 5W/10W·Pi4 측정을 구분한다.
정해진 기간 내 보고가 어려운 시험은 미완료로 남기며, 제목에서 입증된 실시간 성능으로 표현하지 않는다.

## 진행 순서

1. 고정 범위 문서와 기존 영상 pose 감사.
2. 원고를 이 범위와 증거 수준에 맞게 개정; 기존 실패 보존.
3. 별도 장소의 고정 RGB-D 자료 확보·설치/분할 감사 후 주 검증 목록 확정.
4. frozen 후보와 제어군 평가 및 장면별 실패 분석.
5. 위험 목표·비상 갱신 개선이 필요하면 별도 개발 실험으로 수행; 또 다른 fresh holdout 필요.
6. 실제 목표 장치의 프레임 예산과 장기 안정성 측정.
